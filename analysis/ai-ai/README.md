# AI-AI Analysis

This directory contains within-condition analysis notebooks for the AI-AI simulated baseline.

## Notebooks

*(To be added after running the simulation pipeline)*

- `valence_alignment.Rmd` - Valence alignment analysis
- `semantic_exploration.Rmd` - Semantic exploration patterns
- `surface_metrics.Rmd` - Text descriptives analysis

## Data

The AI-AI condition uses simulated data generated by `scripts/05_simulate_baseline.py`.

**Models used:**
- gpt-4.1-2025-04-14 (OpenAI)
- claude-sonnet-4-5-20250929 (Anthropic)
- Llama-3.3-70B-Instruct (OpenRouter)
- Qwen2.5-72B-Instruct (OpenRouter)

**Dataset:**
- 40 stories total (10 per model)
- 10 turns per story
- Cycling through workshop prompts 1, 2, 3

## Running the Pipeline

1. Set API keys:
```bash
export OPENAI_API_KEY=your_key
export ANTHROPIC_API_KEY=your_key
export OPENROUTER_API_KEY=your_key
```

2. Generate simulated data:
```bash
python scripts/05_simulate_baseline.py
```

3. Set active experiment:
```yaml
# In config.yaml
active_experiment: "ai-ai"
```

4. Run pipeline scripts 02-08:
```bash
python scripts/02_clean_dataset.py
python scripts/03_compute_embeddings.py
python scripts/04_compute_sentiment.py
# ... etc
```
